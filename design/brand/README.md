# Brand source

Working files for the RunIt identity. **Nothing here is shipped.** The assets the app
actually uses are `assets/icon.png`, `assets/adaptive-icon.png` and
`assets/splash-icon.png`, generated by `tools/make-icons.mjs` and referenced from
`app.json`.

These live here rather than in `assets/` for exactly that reason: `assets/` is the
directory `app.json` reads, and a stray `.svg` beside the three PNGs invites someone to
assume it is wired up when it is not.

- `runit-logo.svg` — a wordmark exploring the spotlight cast from the dot of the `I`,
  drawn against `#1A1A2E` in the app's own `secondary` (`#E8D4B8`) and `accent`
  (`#38BDF8`), plus a warm amber that is **not** a theme token.
- `runit-logo-preview.html` — opens that SVG at several sizes. Load it directly in a
  browser; it references the SVG by relative path, so the two move together.

## What is unresolved

**"RunIt" contains no lowercase `i`.** The capital `I` carries no tittle, so the dot the
concept depends on does not exist in the name as spelled. Giving the `I` a dot is a
deliberate anomaly, not an oversight, and it has to be decided rather than assumed.

**The amber is not a token.** `secondary` is `oklch(87.91% 0.043 76.31)` in dark — amber's
own hue family at low chroma — and `oklch(44.28% 0.116 46.14)` in light. A brand amber
derived from those two rather than picked would keep the mark inside the existing system;
whether it may also enter `design/theme.css` is an open question, and that file is the
imported canvas spec, locked to `src/theme/tokens.ts` by `tokens.test.ts`.

**There is already a shipped mark** with a written rationale — `8f97859`, "three rows with
the middle one lit and led by a dot: the run of show". Its generator is wired to no npm
script and no gate, so nothing regenerates or verifies it. Any replacement inherits that
gap and should close it.
