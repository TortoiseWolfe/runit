Worth knowing before you send it

The install link points at one address that never goes stale.

The invitation links to runit-app.pages.dev/i/<your code> rather than at a download. That page is where install instructions live, so an email you sent in March still works in October — the page changes, your email does not.

Do not paste a build link into an invitation. Those point at one specific build and go stale the moment a new one exists.

iPhone and Android are not the same right now.

Android installs from a link, no account, no store, no waiting.

iPhone still needs each person added by hand, because Apple requires it while an app is in private testing. Ask them to reply, and they get added. That changes once RunIt is through Apple's beta review, after which one public link works for everyone.
